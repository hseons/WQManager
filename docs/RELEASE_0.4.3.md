## 边界与后续验收

- 文本最多显示 64 KiB；图片预览最长边最多 4096 像素。完整源文件可分享。
- plist 最大 8 MiB，每页 200 项。数据库与 WAL 合计最大 512 MiB；先关闭来源 App，
  再制作工作副本。复制前后检查身份、大小、mtime/ctime；变化、链接和非空恢复日志会停止读取。
  这是尽力的稳定副本检查，不是并发写入下的原子数据库快照。
- SQLite 每页 100 行、最多 128 列/2 MiB 显示数据、每值 4 KiB，BLOB 仅显示大小；
  查询设有 3 秒进度期限。CSV 沿用值上限，最多 10000 行/16 MiB、10 秒进度期限，
  超限移除未完成文件。加密或自定义格式可能显示读取错误。
- iOS 决定当前备份的后台宽限时间；不承诺后台持续执行。进程退出后由用户明确恢复队列。
- 本轮未安装到真机。真实容器、签名/App Group、受限文件、后台中断和容器变更矩阵仍待验收。
  App Groups/扩展只读总览与目录变化实验没有在本轮开放。
