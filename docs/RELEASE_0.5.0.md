# 0.5（构建 1）全局搜索、空间趋势与导出闭环发布验证

日期：2026-11-18（Asia/Shanghai）。主 App 与分享扩展显示版本 0.5，构建号 1；
内部发布修订为 0.5.0，Git 标签应为 v0.5.0。

## 本次完成

1. **全局文件搜索**：应用工具 →「全局文件搜索」，扫描所有可访问 App 的用户文件。
   支持文件名、相对路径、App 名多关键词匹配，类型与最小大小筛选，
   路径/大小/最新三种排序，最多显示 300 条；结果随扫描逐步出现，
   可取消、可不离开页面预览或打开所在目录。默认排除 `Library/Caches` 与 `tmp`。
2. **空间变化**：排名支持「较上次 / 近 7 天 / 近 30 天」三档，按增长排序，
   底部显示已知占用与合计变化，并新增全部 App 合计趋势图；
   单 App 详情显示当前大小、较上次变化、近 7 天变化和扫描历史。
   历史最多保留 60 次快照，容器更换或缺少有效测量后重新累计。
3. **文件审计与导出**：
   - 大文件与重复文件审计，按 App 分组，重复项经 SHA-256 确认。
   - 重复清理要求每个 App 至少保留一份，删除进入空间透镜回收站，记录写入历史。
   - 导出中心支持分享或存储到「文件」，只有目标写入完成/用户取消才更新历史；
     取消、失败、窗口消失会清理 `WQMDataExport-*` 临时目录。
4. **一致性与安全修复**：
   - 修复 `wq_drop_grant` 的 NSNumber 指针布尔判断和空间透镜路径列表的 nil 参数警告。
   - 修复排名页底部被悬浮 Tab Bar 遮挡。
   - 启动时把上次残留的 Running 操作标记为「已中断」，不再永久显示进行中。
   - 清理 14 个未使用本地化 key，中英文保持 813 个 key 对齐。

## 边界与后续验收

- **本轮产物未签名**，未在真机安装。真实容器、App Group 签名、
  真机大目录、分享/存储到「文件」以及强制中断场景仍需安装后验收。
- 全局搜索与文件审计按 App 串行扫描；单个 App 目录上限为
  50,000 个文件 / 100,000 个条目。超大 App（微信 12.88 GB 级别）
  的冷扫描耗时与取消响应需要在真机记录。
- 空间趋势依赖扫描历史；首次使用或样本不足时窗口显示「—」，
  这是预期行为，不代表 0 变化。
- 数据完全持平时合计趋势图是一条水平线；视觉信息有限，但数值正确。
- 导出选择面板打开时强制退出 App，会留下 Running 记录；
  下次启动会被标记为已中断。临时目录由 housekeeping 清理。
- 存储到「文件」的复制失败提示由系统文件选择器负责，App 侧只能收到成功/取消。
- 本版不包含 zip 导出、按 App 的导出历史、回滚快照；留待后续版本。
